Estos tres comandos son los pasos básicos para guardar tu trabajo con Git. 
usas git add para elegir cuáles archivos nuevos o cambiados quieres guardar.
ejecutas git commit p y dejar ese avance registrado en la memoria de tu computadora con una nota donde explicas que hiciste y
usas git push para subir esos cambios a la nube en este caso github y asi actualizar tu cuenta de GitHub, para que todo quede respaldado en la nube.
